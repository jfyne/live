Live v2 Alpine.js Example

This example demonstrates the v2 islands architecture combined with Alpine.js for client-side interactions.

Type in the search box to see autocomplete suggestions. Click a suggestion to add it to your selected list.

Features Demonstrated:

  • Islands Architecture: The autocomplete is an independent live island
  • Alpine.js Integration: Client-side UI state (dropdown open/close) managed by Alpine.js
  • Server-Side Filtering: Search suggestions are filtered on the server
  • Deduplication: Selecting the same item twice only adds it once
