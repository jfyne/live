Live v2 Buttons Example

This example demonstrates button clicks and keyboard shortcuts using the v2 islands architecture.

Use the buttons or press ArrowUp/ArrowDown to change the count.

0
Keyboard shortcuts: ArrowUp to increment, ArrowDown to decrement

Features Demonstrated:

  • Button Events: live-click="inc" and live-click="dec"
  • Keyboard Shortcuts: live-window-keyup with live-key="ArrowUp" and live-key="ArrowDown"
  • Islands Architecture: Independent component with isolated state
