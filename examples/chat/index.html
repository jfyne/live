Live v2 Chat Example

This example demonstrates the v2 islands architecture with a real-time chat powered by the broadcast system.

This is a cluster demo: the server runs on two ports (:8080 and :8081). Open tabs on both ports and messages will propagate across all connected clients via the shared broadcast transport.

Features Demonstrated:

  • Broadcast: Messages sent from one client are delivered to all connected clients via live.Broadcast
  • Multi-Server: Two server instances share a LocalTransport — in production, use a Redis transport
  • live-update="append": New messages are appended to the DOM without a full re-render
  • Self Handlers: The newmessage self handler receives broadcast events and updates state
