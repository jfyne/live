Live v2 Clocks Example

This example demonstrates multiple clock islands on one page, each showing a different timezone.

Each clock is an independent island that updates every second using self-directed events.

Features Demonstrated:

  • Multiple Islands: Multiple instances of the same island type on one page
  • Independent State: Each clock island independently tracks its own timezone
  • HandleSelf: The "tick" self-event handler updates the clock time on each tick
  • Server Push: The server sends updates to the client without any client interaction
  • WithEventDelay: Configures a 1-second delay before re-delivering the "tick" event
  • SendSelf: Called in mount to schedule the first tick
