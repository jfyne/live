Features Demonstrated:

  • Islands Architecture: Each <live-island> is an independent component
  • Server-Side State: Initial values are defined on the server and rendered into the HTML
  • State Isolation: Each counter maintains its own state independently
  • Shared Transport: All islands share a single WebSocket or SSE connection
  • Event Handling: Click events are routed to the correct island instance
