Live v2 Hooks Example

This example demonstrates client-side hooks for handling server-sent events in the v2 islands architecture.

When the button is clicked, the server returns an error. The engine automatically sends an error event to the client, which is caught by the registered hook and displayed as an alert.

Click the button below to trigger a server error. The error will be caught and sent to this hook.

Features Demonstrated:

  • Client Hooks: window.Hooks registers event handlers on the client side
  • Error Handling: Server errors are automatically forwarded to the client as error events
  • Hook Communication: this.handleEvent("err", ...) listens for server-sent events
  • Server Resilience: Errors do not crash the server; multiple errors are handled gracefully
